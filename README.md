# BVH 剪辑工具 (BVH Change Tool)

浏览器里运行的 BVH 动画剪辑工具：把 `.bvh` 拖进窗口 → 3D 预览骨骼动作与**根轨迹** → 设置入点/出点 → 导出裁剪后的 BVH 文件。纯前端实现，同时也能直接双击 `index.html` 打开（three.js 走 CDN）。

## 快速开始

```bash
./start.sh                 # 启动本地服务器（默认 http://localhost:8080），自动打开浏览器
```

如果 `start.sh` 用不了，也可以手动：

```bash
python3 serve.py --port 8080      # 推荐：强制 no-store，避免浏览器用旧缓存页面
python3 -m http.server 8080       # 备用
```

打开页面后把 `.bvh` 文件拖进窗口（或点「📂 导入」）。

## 功能

- **3D 骨骼预览**：球体关节 + 圆柱骨骼，按 BVH 层级实时求世界坐标
- **根轨迹（轨迹）**：整段根关节路径（淡蓝）+ 已播放部分（橙色）+ 当前位置圆点；勾选框可开关
- **时间轴**：按根关节位移生成运动波形，可拖动播放头、缩放（滚轮）、中键平移
- **裁剪**：设置入/出点，导出裁剪后的 BVH（文件头与通道格式保持标准 BVH 规范）
- **播放**：变速（0.25x–4x）、循环；载入后自动把相机与地面网格框到整段运动范围
- **自检**：载入后校验骨骼是否为正常直立姿态，视口左上角显示版本与自检结果

## 快捷键

| 按键 | 功能 |
| --- | --- |
| `Space` | 播放 / 暂停 |
| `←` / `→` | 上一帧 / 下一帧（`Shift` 加速 10 帧） |
| `I` / `O` | 设置入点 / 出点 |
| `Home` / `End` | 跳到起点 / 终点 |
| `L` | 循环开关 |
| `F` | 重置视角 |
| `Esc` | 暂停 |

## 本次修复（v2.1）

1. **前向运动学（FK）矩阵约定错误**：原实现把平移放在矩阵第 12/13/14 位（行向量写法），却按列向量（平移在 3/7/11 位）做矩阵乘法和取位置，导致父关节变换的平移被丢弃；另外 `compose(_v, _q, _v.set(1,1,1))` 会先把位置参数覆盖成 `(1,1,1)`。两者叠加的结果是：所有关节偏移都变成 `(1,1,1)`，骨骼错乱、根位移丢失（小人「躺」着、末端关节甩飞）。现已统一为「行主序 + 末列为平移 + `world = parent * local`」，旋转按 BVH 规范 `R = Rz·Ry·Rx`。
2. **轨迹不显示**：`setShowTrail` 未实现（勾选会报错），现已实现根轨迹绘制，默认开启。
3. **视角与地面**：载入后按整段轨迹取景、网格跟随轨迹范围，并把角色最低点对齐地面。
4. **缓存防护**：新增 `serve.py`（强制 `no-store`），`start.sh` 优先使用它并带时间戳参数打开浏览器；页面左上角显示版本徽标 + 骨骼自检，避免「改了代码但浏览器还在跑旧页面」。

## 与 Blender 的一致性校验

用 Blender 5.2.1 自带 BVH 导入器（`bpy.ops.import_anim.bvh`）作为参考实现，与工具的 FK 结果逐关节比对（BVH 为 Y 轴向上，Blender 世界为 Z 轴向上，按标准 `(X, -Z, Y)` 换算）：

| 帧 | 关节数 | 位置最大偏差 | 关节间距离最大偏差 |
| --- | --- | --- | --- |
| 0 | 57 | 0.000032 | 0.000028 |
| 3000 | 57 | 0.000024 | 0.000021 |
| 6000 | 57 | 0.000062 | 0.000024 |

角色高约 160 单位，偏差量级为 Blender 内部 float32 量化误差，即两者一致；全程根轨迹（每 40 帧采样）同样完全重合。可视化对比见 `与Blender对比_修复验证.png`（蓝＝工具，橙＝Blender）。

## 目录说明

| 路径 | 说明 |
| --- | --- |
| `index.html` | **唯一入口**，自包含全部逻辑，只从 CDN 加载 three.js |
| `serve.py` / `start.sh` | 本地服务器（禁用浏览器缓存）与启动脚本 |
| `js/`、`css/` | 早期模块化重构的残留文件，当前未被 `index.html` 引用（其中 `js/bvh-parser.js` 的 FK 已同步修复） |
| `test.html` | three.js 渲染冒烟测试页 |
| `与Blender对比_修复验证.png` | 与 Blender 的姿态/轨迹叠加对比图 |

## 已知限制

- 需要联网从 CDN 加载 three.js（如需离线可把 three.js 下载到本地并改 `<script type="importmap">`）
- 相机默认固定机位俯视整段轨迹，便于观察路径；查看单帧细节时需自行缩放
